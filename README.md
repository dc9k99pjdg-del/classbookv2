# สมุดประจำวิชา (แบบติดตั้งในเครื่อง)

ข้อมูลนักเรียนทั้งหมดเก็บในเครื่องของครูแต่ละคนเท่านั้น ไม่ส่งไปที่เซิร์ฟเวอร์ใด
ไฟล์ในโฟลเดอร์นี้คือตัวแอป ไม่มีข้อมูลนักเรียนอยู่ในไฟล์ใดเลย

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอป |
| sw.js | ทำให้แอปเปิดได้แม้ไม่มีอินเทอร์เน็ต |
| manifest.webmanifest, icon-*.png | ชื่อและไอคอนเมื่อเพิ่มลงหน้าจอโฮม |
| xlsx.full.min.js, jszip.min.js | ตัวอ่านและสร้างไฟล์ Excel/Word |

## ขั้นที่ 1 วางแอปบน GitHub Pages (ทำครั้งเดียว โดยผู้ดูแล)

1. เข้า https://github.com แล้วเข้าสู่ระบบด้วยบัญชีที่จะใช้ดูแลแอป
2. กดปุ่ม **New** (สร้าง repository) ตั้งชื่อ เช่น `classbook` เลือก **Public** แล้วกด **Create repository**
   (GitHub Pages แบบฟรีต้องเป็น Public ซึ่งปลอดภัย เพราะในนี้มีแค่ตัวแอป ไม่มีข้อมูลนักเรียน)
3. ในหน้า repository กด **uploading an existing file** (หรือ Add file > Upload files)
4. เลือกไฟล์ทั้งหมด 10 ไฟล์ในโฟลเดอร์นี้ แล้วกด **Commit changes** (ทุกไฟล์อยู่ชั้นเดียวกัน ไม่มีโฟลเดอร์ย่อย)
5. ไปที่ **Settings > Pages** ช่อง Source เลือก **Deploy from a branch**, Branch เลือก **main** และ **/(root)** แล้วกด **Save**
6. รอ 1–2 นาที หน้าเดียวกันจะแสดงลิงก์ เช่น `https://ชื่อบัญชี.github.io/classbook/`
7. ส่งลิงก์นี้ให้ครูทางไลน์โรงเรียน

### เมื่อมีแอปรุ่นใหม่
อัปโหลดไฟล์ที่เปลี่ยนทับของเดิมในขั้นที่ 3–4 ครูเปิดแอปขณะมีอินเทอร์เน็ตก็จะได้รุ่นใหม่ ข้อมูลในเครื่องของครูไม่หาย

## ขั้นที่ 2 ครูติดตั้งแอปลงเครื่อง

ในไลน์ ให้กดค้างที่ลิงก์แล้วเลือกเปิดด้วย Safari หรือ Chrome (ห้ามเปิดในไลน์ เพราะจะติดตั้งไม่ได้)

- **iPad / iPhone (Safari):** กดปุ่มแชร์ ⬆ > **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** กด ⋮ > **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
- **คอมพิวเตอร์ (Chrome / Edge):** กดไอคอนติดตั้ง ⊕ ที่ช่องที่อยู่เว็บ

หลังจากนั้นเปิดจากไอคอน “สมุดประจำวิชา” ได้เลย ใช้ได้แม้ไม่มีอินเทอร์เน็ต

## ขั้นที่ 3 สำรองข้อมูล (สำคัญ)

- แท็บ **ตั้งค่า > สำรองข้อมูล > สำรองข้อมูลทุกวิชา**
  - บน iPad/มือถือ เลือก **บันทึกไปยังไฟล์** แล้วเลือก iCloud Drive หรือ Google Drive (บัญชี @chainatpit.ac.th) หรือเลือกแอป Google Drive โดยตรง
  - บนคอมพิวเตอร์ ไฟล์จะอยู่ในโฟลเดอร์ดาวน์โหลด
- แอปจะเตือนเมื่อไม่ได้สำรองครบ 7 วัน
- แอปเก็บสำเนาอัตโนมัติในเครื่องวันละ 1 ชุด ย้อนหลัง 7 วัน ใช้ย้อนกลับเมื่อกรอกผิด แต่ถ้าเครื่องหาย เสีย หรือลบแอป สำเนานี้หายไปด้วย

## ย้ายไปเครื่องใหม่

1. เครื่องเดิม: สำรองข้อมูลทุกวิชา
2. เครื่องใหม่: ติดตั้งแอป แล้วกด **ย้ายข้อมูลจากเครื่องเดิม (ไฟล์สำรองทุกวิชา)** และเลือกไฟล์

## ย้ายข้อมูลจากแอปรุ่นเดิม (บน Claude)

1. ในแอปเดิม เปิดสมุดทีละวิชา แล้วกด **ตั้งค่า > ส่งออก > สำรองข้อมูลสมุดนี้**
2. ในแอปใหม่ กด **เปลี่ยนวิชา > นำเข้าสมุดจากไฟล์สำรองรายวิชา** แล้วเลือกไฟล์ ทำทีละวิชา

## ข้อควรระวัง

- อย่าล้างประวัติหรือข้อมูลเว็บไซต์ของ Safari/Chrome สำหรับลิงก์แอปนี้
- ครูแต่ละคนกรอกรหัสครูและชื่อครูของตัวเองที่ **ตั้งค่า > ครูผู้สอน** ก่อนส่งออกไฟล์ BookMark
